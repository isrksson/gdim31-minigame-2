2. ```_spriteRenderer.color = new Color(r, 0.2f, 0.2f);```
This code line accesses spriteRenderer's color component and sets its value to a new Color object with a value of (r, 0.2f, 0.2f) in rgb. The period allows us to access an object's member variable. The keyword "new" allows us to create a new object.
